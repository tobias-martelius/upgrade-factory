# Project language

- Communicate with the user in Swedish unless they request another language.
- Write and maintain project documentation in British English, even when the request is in Swedish. Use British spelling, such as “behaviour”, “authorise”, “organise” and “licence” (noun).
- Preserve exact command names, identifiers, JSON keys, file paths and third-party product names when translating documentation.
- Do not translate or modify standard licence texts; retain their official wording.
